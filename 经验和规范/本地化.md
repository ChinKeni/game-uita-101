# 本地化

> 参考 [本地化（MDN）](https://developer.mozilla.org/zh-CN/docs/Glossary/Localization)文档说明，此处以语言文本为主摘选。

## 多国语言支持

通过配置一个中间的 ID，去根据当前所开启的语言，重新对 [文本(Text)](../可视组件/文本(Text).md) 组件内容进行赋值。

管理文本 ID 的方式有很多

### 手动配置

填写配置好的本地化表 ID，但是需要对资产的文本内容进行管理，避免开发文本外漏。

优点：开发期间策划不用想具体文案内容，等确认了再填入。

缺点：需要严格把控合管理那些文本组件内容，避免出现开发乱填的内容上线。

### 自动生成

这个方案是扫描资产下的文本，根据文本生成对应的 ID 表，策划只要把表给到本地化翻译即可，这个在开发前策划就需要准备好文本。

优点：少去了建表的环节，节省一些重复劳作力。

缺点：需要构建出一个完整的管理规则，得思考策划会改文本，以及合并共有字段的方案。

‍

## 特殊语言支持

1. 阿拉伯\希伯来文：[从右向左（RTL）](https://developer.mozilla.org/zh-CN/docs/Glossary/RTL) 书写。

2. 日文：对日本的汉字进行假名注音（Ruby）。
